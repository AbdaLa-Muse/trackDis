Trading Setup Rules

Trading Setup Rules Cheat Sheet

SETUP 1

5M Break + Gap / Breaker Block

1. HTF POI ama Liquidity Sweep

  • 1H ama 4H Order Block
  • ama previous 1H ama 4H Breaker Block
  • Liquidity Sweep = 1H ama 4H Gap fill
  • mararka qaar 15M Gap fill

2. 5M Confirmation

  • 5M Structure Break
  • ama 5M IFVG
  • waa inuu waafaqaa 3-candle pattern-ka

3. Entry Area

  • Gap / FVG
  • ama small previous Breaker Block
  • price-ku waa inuu dib ugu soo laabtaa meeshaas kadibna ka kaco
FlowHTF POI / Liquidity Sweep → 5M Structure Break ama IFVG → Gap/FVG ama Small Breaker Block → Retrace → Entry → Continuation
SETUP 2

5M Inducement + Liquidity Sweep

1. HTF POI ama Liquidity Sweep

  • Order Block
  • 1H ama 4H Gap fill
  • mararka qaar 15M Gap fill

2. 5M Confirmation

  • 5M Structure Break
  • ama 5M IFVG
  • waa inuu waafaqaa 3-candle pattern-ka

3. 5M Inducement

  • break-ka marka uu dhacayo waa inuu sameeyaa 5M Inducement
  • Inducement-kaas wuxuu noqdaa 5M Liquidity
  • price-ku waa inuu dib ugu soo laabtaa oo liquidity-gaas sweep-gareeyaa
  • kadibna price-ku waa inuu ka kaco
FlowHTF POI / Liquidity Sweep → 5M Structure Break ama IFVG → 5M Inducement → Liquidity Sweep → Entry → Continuation
SETUP 3

Consolidation Sweep + 5M Structure Break

1. HTF POI ama Liquidity Sweep

  • Order Block
  • 1H ama 4H Gap fill
  • mararka qaar 15M Gap fill

2. 5M Consolidation

  • marka hore Consolidation
  • kadib Consolidation Sweep
  • kadib 5M Structure Break

3. Retrace kadib Break-ka

  • Gap / FVG
  • ama Inducement oo marka hore la sweep-gareeyo
  • kadib price-ku waa inuu ka kaco
FlowHTF POI / Liquidity Sweep → 5M Consolidation → Consolidation Sweep → 5M Structure Break → Gap/FVG ama Inducement Sweep → Entry → Continuation
SETUP 4

5M / 15M / 1H Alignment + Gap

1. Timeframe Alignment

  • 5M
  • 15M
  • 1H
  • dhammaantood waa inay isku direction yihiin

2. Gap

  • 5M Gap
  • ama 15M Gap

3. Retrace

  • price-ku waa inuu dib ugu soo laabtaa Gap-ka
  • Gap-ka taabtaa ama buuxiyaa
  • kadibna ka kaco
Flow5M + 15M + 1H Alignment → 5M/15M Gap → Retrace / Gap Fill → Entry → Continuation
