# TradeFlow v11.13 — Weekly Analysis

- Adds Weekly Analysis to sidebar and mobile navigation.
- Weekly statistics are calculated live from Daily Reviews; they are not duplicated in Supabase.
- Manual storage is limited to Biggest Mistake, Main Lesson, and Next Week Focus.
- Historical Daily Review edits automatically change weekly calculations.
- Includes week navigation, Good/Normal/Bad classification, best/worst trades, streaks, discipline, setup comparison, strengths/problems, and previous-week comparison.
